# 冰晕模拟器 (Ice Halo Simulator)

基于 WebGPU 计算着色器的大气冰晕蒙特卡洛光线追踪工具。把阳光逐条射入高空卷云里的六角冰晶，
追踪折射与内反射，按冰的色散折射率分出颜色，在天空半球上叠成晕弧图像，并可叠加到用户照片上比对辨认。

## 功能页面

| 页面 | 内容 |
| --- | --- |
| 冰晕模拟 | 太阳高度、光线数、色散分箱、曝光实时调整; 天顶等距方位鱼眼成像; 内置物理自检 |
| 冰晶参数 | 5 种典型卷云预设 + 片状/柱状/乱序三类晶的占比、朝向摆动、纵横比微调 |
| 照片比对 | 上传天空照片, 点击标定太阳位置与角距比例, 模拟晕弧加色叠加 |
| 晕弧图鉴 | 8 种常见冰晕(22°/46° 晕、幻日、环天顶弧、环地平弧、上切弧、幻日环、光柱)的晶型/光路/条件, 一键载入参数 |

## 物理模型

- **几何**: 正六角柱(6 个柱面 + 2 个底面), 纵横比区分片状与柱状。
- **光学**: 矢量形式 Snell 折射定律、未偏振 Fresnel 反射率、全反射判定、俄罗斯轮盘赌处理内反射。
- **色散**: 冰的折射率 Cauchy 拟合 `n(λ)=A+B/λ²`(钠光 n=1.3093), 波长经 CIE XYZ 分段高斯近似转 sRGB。
- **取向**: 片状晶柱轴平均竖直、柱状晶柱轴平均水平, 高斯摆动 σ 可控; 乱序晶各向同性均匀球采样。
- **入射采样**: GPU 用面积重要性采样(按各面投影面积选面、面上均匀取点), 无拒绝、一次成功。

## 关键物理结论(已被测试锁定)

- 22° 晕角半径 = 棱镜最小偏向角 `D_min = 2·asin(n/2) − 60° ≈ 21.78°`。
- 幻日水平方位角距随太阳高度从 22° 单调增大, 由 60° 棱镜焦散驻点解析求出。
- 环天顶弧临界太阳高度 `h_crit = asin(√(2−n²)) ≈ 32.3°`, 超过即侧面全反射、弧消失。

## 技术栈

- TypeScript + Vite
- WebGPU 计算着色器 (WGSL) 做光线追踪与天空成像, 无 WebGPU 时自动回退到 CPU 追踪器 + Canvas 2D
- 无第三方运行时依赖

## 命令

```bash
npm install
npm run dev        # 本地开发
npm test           # CPU 物理校验 (Vitest, 19 项)
npm run test:gpu   # headless Chrome 验证 WGSL 编译/运行/物理一致性/性能
npm run build      # 类型检查 + 生产构建
```

### 验收指标实测

- 22° 晕模拟峰半径与最小偏向角公式相差 < 0.3°(测试断言)。
- 幻日模拟峰与解析焦散公式相差 < 0.5°(测试断言)。
- 环天顶弧在太阳高度 0–32° 存在、33–60° 消失(路径计数断言)。
- 1000 万光线 GPU 出图: AMD RDNA3 上实测外推约 0.5–1.3 秒, 满足 3 秒指标(`npm run test:gpu`)。
